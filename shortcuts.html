Daily Flow

Branches

git checkout -b nameCreate + switch to branch
git checkout mainSwitch to main
git branch -d nameDelete local branch
git branch -aList all branches
git merge nameMerge branch into current
git rebase mainRebase current onto main

Inspection

git log --onelineCompact commit history
git diffUnstaged changes
git diff --stagedStaged changes

Fixes & Undos

git commit --amendEdit last commit message
git reset HEAD~1Undo last commit (keep changes)
git restore fileDiscard unstaged changes
git restore --staged fileUnstage file
git clean -fdRemove untracked files

Never force-push to main/master
